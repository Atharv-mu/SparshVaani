# स्पर्शवाणी (SparshVaani)

**An Accessible Communication and Learning Companion**

SparshVaani is an interactive web application designed to support accessible communication and learning. It brings together visual learning, speech assistance, live captions, and sign-language practice in one user-friendly interface.

The project aims to make everyday communication more inclusive through simple and accessible digital tools.

## ✨ Features

### 1. Reels – Visual Learning
- Explore words and phrases through visual cards.
- Browse different communication categories.
- View English words alongside Hindi translations.
- Listen to words using text-to-speech.
- Like and save useful words for later.
- Navigate between cards using keyboard shortcuts.

### 2. Live Captions
- Convert spoken audio into on-screen text using browser speech recognition.
- Supports English (India), Hindi (India), and English (US).
- Start and stop live captioning.
- Clear or copy recognized text.
- View captions in a large, readable format.

### 3. Speak – Text to Speech
- Type messages and convert them into spoken audio.
- Adjust speech speed.
- Use ready-made communication phrases.
- Create and save custom phrases.
- Support communication through spoken output.

### 4. Add Reel – Custom Learning Cards
- Create personalized visual learning cards.
- Add an emoji, English word or phrase, and Hindi translation.
- Optionally attach a video clip.
- Publish and manage custom cards.

### 5. Sign Mirror – Sign Practice
- Display a selected visual card as a reference.
- Access the device camera for mirror-based practice.
- View your camera feed in a mirrored layout.
- Practice signs and gestures while referring to the selected card.

## 🛠️ Technologies Used

- **HTML5** – Application structure
- **CSS3** – Styling and responsive layout
- **JavaScript** – Application functionality
- **React 18** – UI components and state management
- **HTM** – JSX-like syntax without a build step
- **Tailwind CSS** – Utility-based styling
- **Phosphor Icons** – Interface icons
- **Web Speech API** – Speech recognition and text-to-speech
- **MediaDevices API** – Camera access
- **Local Storage** – Saving user data in the browser

## 🚀 Getting Started

### Prerequisites

- A modern web browser.
- An internet connection.
- A working microphone for live captions and speech-related features.
- A camera for Sign Mirror.

### Installation

1. Download or copy the project source code.
2. Save the code as `index.html`.
3. Open the file in a modern web browser.

For camera and microphone functionality, run the application through a secure context such as `localhost` or HTTPS.

## 💾 Data Storage

SparshVaani uses browser local storage to retain selected information, including:
- Custom reels
- Liked words
- Saved words
- Custom communication phrases

## 🔐 Privacy

- Camera and microphone access require user permission.
- Media access is controlled through browser permissions.
- The application does not include a built-in user account or cloud synchronization system.
- Saved application data remains in the browser's local storage.

## 🎯 Project Objective

The objective of SparshVaani is to provide an approachable digital platform that encourages accessible communication through visual content, speech assistance, captions, and sign-practice support.

By combining these tools in a single interface, the project aims to make communication support easier to access and use.
